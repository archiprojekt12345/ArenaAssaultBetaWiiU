# Arena Assault — Wii U
Cześć wszystkim...
Strzelanka z widokiem zza pleców dla **Nintendo Wii U z Aroma**. W trybie Conquest dwie drużyny walczą o punkty A, B i C. Gra dla jednego gracza z botami, z mapą taktyczną na GamePadzie.

**Aktualna wersja: 0.9.5 — Interface Preview (testowa).** Polski interfejs, czytelniejsze oznaczenia punktów oraz poprawione informacje o trafieniach i walce.
Planowany termin wydania nowej wersji "Conquest" to bedzie przełom Października oraz Listopada
## Pobieranie i instalacja

1. [Pobierz paczkę SD 0.9.5](https://github.com/archiprojekt12345/ArenaAssaultBetaWiiU/raw/refs/heads/main/downloads/ArenaAssault_0.9.5_Interface_PREVIEW_SD.zip).
2. Rozpakuj ZIP i skopiuj folder `wiiu` do katalogu głównego karty SD.
3. Uruchom Wii U z Aroma i wybierz **Arena Assault 0.9.5 Interfejs**.

Wersja testowa działa jako osobna aplikacja typu "homebrew" i ma własny zapis. Wszystkie wymagane zasoby są w pliku .WUHB.
