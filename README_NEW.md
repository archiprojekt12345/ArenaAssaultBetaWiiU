# Arena Assault Wii U — ALPHA 0.8.3

Gotowa wersja gry **Arena Assault** dla konsoli Wii U z systemem **Aroma**.

To repozytorium służy wyłącznie do dystrybucji gotowego pliku WUHB. Kod źródłowy nie jest publikowany w tym repozytorium.

## Instalacja

1. Wyłącz Wii U i wyjmij kartę SD.
2. Pobierz zawartość repozytorium albo paczkę wydania.
3. Skopiuj katalog `wiiu` do katalogu głównego karty SD.
4. Sprawdź, czy plik znajduje się dokładnie tutaj:

```text
SD:/wiiu/apps/ArenaAssault/ArenaAssault.wuhb
```

5. Włóż kartę SD do Wii U i uruchom Aroma.
6. Arena Assault pojawi się w menu Wii U.

Nie trzeba kopiować oddzielnych modeli, tekstur ani pliku `glslcompiler.rpl`. Wymagana zawartość jest umieszczona wewnątrz pliku WUHB.

## Sterowanie menu

- **A** — rozpoczęcie lub wznowienie gry,
- **PLUS** — pauza lub wznowienie,
- **B podczas pauzy** — powrót do menu.
