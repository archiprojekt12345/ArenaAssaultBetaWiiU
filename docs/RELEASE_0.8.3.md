# Arena Assault Wii U — ALPHA 0.8.3

## Zawartość wydania

```text
wiiu/apps/ArenaAssault/ArenaAssault.wuhb
```

Plik WUHB zawiera aplikację i wymaganą zawartość uruchomieniową. Użytkownik nie musi osobno kopiować modeli, tekstur ani `glslcompiler.rpl`.

## Integralność pliku

- rozmiar: `1 537 124 bajty`
- SHA-256: `fe634edf6c5520977dbb0e6db1d115bc14d3bc3448cc7b27325ca3b322a4101b`

## Instalacja

Skopiuj katalog `wiiu` do katalogu głównego karty SD. Po uruchomieniu Aroma gra powinna pojawić się w menu Wii U.
