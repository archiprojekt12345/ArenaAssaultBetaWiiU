## Instalacja

1. Wyłącz Wii U i wyjmij kartę SD.
2. Skopiuj katalog `wiiu` do katalogu głównego karty SD.
3. Sprawdź, czy plik znajduje się pod `SD:/wiiu/apps/ArenaAssault/ArenaAssault.wuhb`.
4. Włóż kartę do Wii U i uruchom Aroma.

Nie trzeba kopiować osobnych modeli, tekstur ani `glslcompiler.rpl`.

## Sterowanie menu

- `A` — rozpocznij / wznów,
- `PLUS` — pauza / wznów,
- `B` podczas pauzy — powrót do menu.
